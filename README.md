📝 TaskMate — A Simple Task Manager

TaskMate is a lightweight Python-based task manager that helps you organize your daily to-dos efficiently.
It uses SQLite as a local database to store tasks with their names, due dates, and completion status.

🚀 Features
➕ Add Tasks: Quickly add new tasks with due dates
📋 View Tasks: See all your pending and completed tasks in a simple console view
💾 Auto Database Setup: Automatically creates a local tasks.db file if it doesn’t exist
✅ Status Tracking: Each task includes a status field (default: Pending)

🧰 Built With
Python 3
SQLite3 (built-in database module)

🖥️ How to Run
Clone the repository:

git clone https://github.com/yourusername/TaskMate.git
cd TaskMate

Run the script:
python task_manager.py

Enter your task name and due date when prompted.
